# 查找入口文件

本文沿用 Vue 3.2 系列片段，以 [v3.2.47](https://github.com/vuejs/core/tree/v3.2.47) 作为对照入口。片段有省略，仅用于解释调用关系；Vue 3.5.43 的入口选择在末尾单独说明。

先明确问题：createApp 为什么能创建应用，而 DOM 要等到 app.mount 才出现？从创建应用的入口开始，再看平台渲染器如何接入。

:::note

其实不去了解项目结构，大概也能找到自己想看的内容。文件名和文件夹的名称，定义的很规范。如果你有明确的目的，直接打开 packages 文件夹，找相应内容即可。

:::

## rollup 配置文件

发布一个包，一般都需要经过打包流程。直接打开 Vue 的 package.json 文件，会发现包的入口文件指向的是打包后的 dist 目录。想找到真正的源码入口，需要了解打包流程。

Vue 3 使用 rollup 进行打包，打包命令如下：

```js
"build": "node scripts/build.js",
```

build.js 根据命令参数选择目标包和产物格式，再通过 execa 调用 Rollup；应用实际加载哪个产物，还要看包的导出配置与构建工具。

根项目下有 rollup 的配置文件，查看配置文件，可以找到代码的入口文件，区分运行时和完整版：

```js
let entryFile = /runtime$/.test(format) ? `src/runtime.ts` : `src/index.ts` // 根据产物格式选择运行时或完整版入口
--snip--
return {
    input: resolve(entryFile), // rollup 指定入口文件
    --snip--
  }
```

需要看运行时编译时追踪 packages/vue/src/index.ts；只看预编译 SFC 的运行过程，packages/vue/src/runtime.ts 更直接。两种入口最终都会导出 runtime-dom 的 API，createApp 主线相同。

## createApp

找到入口后，先明确目的，一般的 Vue 项目都是使用 createApp 创建实例，接着调用实例上的 mount 方法，将内容展现到浏览器上，接下来就查找 createApp。

完整版入口中与本篇有关的导出如下：compile 来自运行时编译器，export * 则导出 runtime-dom 的公开 API，并不是只有两个 API：

```typescript
export { compileToFunction as compile };
export * from "@vue/runtime-dom";
```

接着看 runtime-dom 这个包，在 index.ts 中找到了 createApp 方法。


## Renderer

接下来看 ensureRenderer 干了什么，一路查找最终找到 baseCreateRenderer，这个方法很复杂，里面涉及到 patch 逻辑，需要时再细看，现在简单找 createApp：

```typescript

  options: RendererOptions,
  createHydrationFns?: typeof createHydrationFunctions
): any {

    -- snip --

  return {
    render,
    hydrate,
    // render 和 hydrate 都是方法体内提供的
```

最终到了 createAppAPI 方法，createAppAPI 返回一个方法，这个方法创建了 app 实例：

这里面，属性和 mount 方法我保留了。剩下还有很多，比如 app.use、app.component 之类的方法，主要就是检查参数是否合法，往全局对应属性上注册内容。

`const context = createAppContext() `，createAppContext 实际上就是返回了一个初始状态的 context，也是挂载后的 appContext 属性：

```typescript
export function createAppContext(): AppContext {
  return {
    app: null as any,
    config: {
      isNativeTag: NO,
      performance: false,
      globalProperties: {},
      optionMergeStrategies: {},
      errorHandler: undefined,
      warnHandler: undefined,
      compilerOptions: {},
    },
    mixins: [],
    components: {},
    directives: {},
    provides: Object.create(null),
    optionsCache: new WeakMap(),
    propsCache: new WeakMap(),
    emitsCache: new WeakMap(),
  };
}
```

每次 createApp 都创建独立的 appContext，组件注册、全局配置和 app.provide 的资源属于这个应用。同一页面的两个应用不会自动共享这些内容；创建上下文也不意味着对传入的业务对象做了深拷贝。

## 把调用链连起来

```text
createApp(App)
  → runtime-dom：ensureRenderer()
  → runtime-core：createRenderer() / baseCreateRenderer()
  → createAppAPI(render, hydrate)
  → 创建 app 与 appContext

app.mount('#app')
  → runtime-dom：解析 DOM 容器、处理模板和容器内容
  → runtime-core：创建根组件 VNode，关联 appContext
  → render → patch → mountComponent
```

runtime-core 接收 insert、remove、createElement、patchProp 等宿主操作；runtime-dom 用浏览器 DOM API 实现它们。这样，组件与 VNode 的核心逻辑不需要直接依赖 document。入口见 [runtime-dom/index.ts](https://github.com/vuejs/core/blob/v3.2.47/packages/runtime-dom/src/index.ts)、[renderer.ts](https://github.com/vuejs/core/blob/v3.2.47/packages/runtime-core/src/renderer.ts) 与 [apiCreateApp.ts](https://github.com/vuejs/core/blob/v3.2.47/packages/runtime-core/src/apiCreateApp.ts)。

## Vue 3.5 的产物选择

仅凭 `import { createApp } from 'vue'` 不能推断一定加载完整版。[当前 package.json](https://github.com/vuejs/core/blob/v3.5.43/packages/vue/package.json) 同时有 exports 条件入口，以及 module、main 等字段，解析结果取决于环境和构建工具。

- `vue.runtime.esm-bundler.js` 供打包工具使用，不包含运行时模板编译器；常规 Vite SFC 项目的模板已在构建时编译。
- `vue.esm-bundler.js` 包含运行时模板编译能力，适用于需要处理 template 字符串的场景；选用它取决于导入路径、alias 等配置。
- `vue.global.js` 等全局构建供浏览器 script 标签使用，使用方式与打包工具入口不同。

完整版通过 registerRuntimeCompiler 将编译能力接入 runtime-core；runtime-only 入口不注册它。使用 runtime-only 仍然可以写 SFC 模板，只是由构建流程生成 render。详见[工具链指南](https://vuejs.org/guide/scaling-up/tooling.html)。

## 创建、挂载与卸载的边界

createApp 创建应用对象，根组件实例在 mount 时才创建。app.mount 返回根组件的公共实例，不返回 app。先保存应用对象，再注册插件、挂载和卸载：

```ts
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)
const root = app.mount('#app')
// 外部系统移除页面容器前，清理这个应用：
app.unmount()
```

同一个 app 只挂载一次；需要重新挂载就重新 createApp。客户端首次渲染用 createApp；接管服务端生成的 HTML 时用 createSSRApp 的 hydration 路径。API 边界见[应用实例](https://vuejs.org/api/application.html)。下一篇看 [mount 流程](./03-mount.md)。
