## Agent loop

Agent Loop 的流程见[《Agent 学习一》](./2026-03-19.md#agent-loop)。这里补一个 OpenAI 接口的[示例](https://developers.openai.com/api/docs/quickstart)：

```python
from openai import OpenAI

client = OpenAI()

stream = client.responses.create(
    model="gpt-5.6",
    input=[
        {
            "role": "user",
            "content": "Say 'double bubble bath' ten times fast.",
        },
    ],
    stream=True,
)

for event in stream:
    print(event)

```

`input` 放对话消息，`stream=True` 逐步返回事件。输入组织、工具调用和结果处理，这些围绕模型的工程也常叫 Harness。

OpenAI 用 `instructions` 字段或 `role = developer` 的 message 传入角色和要求。提示词怎么写，前面的[使用体验](./2026-03-18.md#如何编写)已经记录过。

## LangChain 和 LangGraph

[之前](./2025-04-18.md)试过 LangChain 的单次调用，这次看它怎样封装带工具的 Agent。[示例代码](https://docs.langchain.com/oss/python/langchain/quickstart)如下：

```python
import urllib.error
import urllib.request

from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.tools import tool
from langgraph.checkpoint.memory import InMemorySaver

SYSTEM_PROMPT = """You are a literary data assistant.

## Capabilities

- `fetch_text_from_url`: loads document text from a URL into the conversation.
Do not guess line counts or positions—ground them in tool results from the saved file."""


@tool
def fetch_text_from_url(url: str) -> str:
    """Fetch the document from a URL.
    """
    req = urllib.request.Request(
        url,
        headers={"User-Agent": "Mozilla/5.0 (compatible; quickstart-research/1.0)"},
    )
    try:
        with urllib.request.urlopen(req, timeout=120) as resp:
            raw = resp.read()
    except urllib.error.URLError as e:
        return f"Fetch failed: {e}"
    text = raw.decode("utf-8", errors="replace")
    return text


model = init_chat_model(
    "gemini-3.1-pro-preview",
    model_provider="google-genai",
    temperature=0.5,
    timeout=600,
    max_tokens=25000,
    streaming=True,
)

checkpointer = InMemorySaver()

agent = create_agent(
    model=model,
    tools=[fetch_text_from_url],
    system_prompt=SYSTEM_PROMPT,
    checkpointer=checkpointer,
)

content = f"""Project Gutenberg hosts a full plain-text copy of F. Scott Fitzgerald's The Great Gatsby.
URL: https://www.gutenberg.org/files/64317/64317-0.txt

Answer as much as you can:

1) How many lines in the complete Gutenberg file contain the substring `Gatsby` (count lines, not occurrences within a line, each line ends with a line break).
2) The 1-based line number of the first line in the file that contains `Daisy`.
3) A two-sentence neutral synopsis.

Do your best on (1) and (2). If at any point you realize you cannot **verify** an exact answer with
your available tools and reasoning, do not fabricate numbers: use `null` for that field and spell out
the limitation in `how_you_computed_counts`. If you encounter any errors please report what the error was and what the error message was."""

agent_result = agent.invoke(
    {"messages": [{"role": "user", "content": content}]},
    config={"configurable": {"thread_id": "great-gatsby-lc"}},
)

print(agent_result["messages"][-1].content_blocks)
```

`@tool` 把 `fetch_text_from_url` 注册成工具，注释 `Fetch the document from a URL` 是工具描述。描述和实现的关系见[前面的说明](./2026-03-19.md#tool-description)。

`init_chat_model` 创建模型，`create_agent` 负责执行工具调用和循环。

checkpointer 保存对话状态。`InMemorySaver` 存在内存里，程序退出后就没了。

这里的 Agent 由 LangGraph 编排。后面拆开看模型、工具、chain 和图的用法。

#### tool

`create_agent` 已经封装了工具循环。单独调用模型时，可以用 `bind_tools` 绑定工具，下面只执行一次请求。更多工具见[官方列表](https://docs.langchain.com/oss/python/integrations/tools)。

```python
from langchain_openai import ChatOpenAI

@tool
def add(a: int, b: int) -> int:
  """Add two integers."""
  return a + b

model = ChatOpenAI(model="gpt-4o")
model_with_tools = model.bind_tools([add])

# 手动执行一次调用
response = model_with_tools.invoke("What is 3 plus 5?")
```

#### chain

模型、提示词等组件都可以按 [Runnable](https://reference.langchain.com/python/langchain-core/runnables/base/Runnable) 的接口调用。用 `|` 或 pipe 把它们连成 chain：

```python
from langchain_deepseek import ChatDeepSeek
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate

# 加载环境变量
import os
from dotenv import load_dotenv

load_dotenv()

template = ChatPromptTemplate(
    [
        ("system", "You are a helpful AI bot. Your name is {name}."),
        ("human", "Hello, how are you doing?"),
        ("ai", "I'm doing well, thanks!"),
        ("human", "{user_input}"),
    ]
)


llm = ChatDeepSeek(
    model="deepseek-v4-flash",
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
    # other params...
)

chain = template | llm | StrOutputParser()

result = chain.invoke(
    {
        "name": "Bob",
        "user_input": "What is your name?",
    }
)

print(result)
```

提示词模板、模型和输出解析器组成一条 chain，继续用 invoke 调用。

用 `RunnableLambda` 包装自定义函数：

```python
from langchain_core.runnables import RunnableLambda

# A RunnableSequence constructed using the `|` operator
sequence = RunnableLambda(lambda x: x + 1) | RunnableLambda(lambda x: x * 2)
sequence.invoke(1)  # 4
sequence.batch([1, 2, 3])  # [4, 6, 8]

# A sequence that contains a RunnableParallel constructed using a dict literal
sequence = RunnableLambda(lambda x: x + 1) | {
    "mul_2": RunnableLambda(lambda x: x * 2),
    "mul_5": RunnableLambda(lambda x: x * 5),
}
sequence.invoke(1)  # {'mul_2': 4, 'mul_5': 10}
```

`|` 串行连接，字典把同一个输入交给多个 Runnable 并行处理。

### LangGraph

RAG 的流程还要判断是否检索，Agent Loop 也要反复调用工具。我用 LangGraph 定义这些分支和循环。

下面把 Agent Loop 写成图：

```python
from langchain.tools import tool
from langchain_deepseek import ChatDeepSeek

from langchain.messages import SystemMessage
from langchain.messages import AnyMessage, ToolMessage
from typing import Literal
from typing_extensions import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END

import operator

from dotenv import load_dotenv

load_dotenv()

model = ChatDeepSeek(model="deepseek-v4-flash", temperature=0)

# 工具
@tool
def multiply(a: int, b: int) -> int:
    """Multiply `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a * b


@tool
def add(a: int, b: int) -> int:
    """Adds `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a + b


@tool
def divide(a: int, b: int) -> float:
    """Divide `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a / b


tools = [add, multiply, divide]
tools_by_name = {tool.name: tool for tool in tools}
model_with_tools = model.bind_tools(tools)

# graph 共享的数据
class MessagesState(TypedDict):
    messages: Annotated[list[AnyMessage], operator.add]
    llm_calls: int


# 调用数据
def llm_call(state: MessagesState):
    """LLM decides whether to call a tool or not"""

    return {
        "messages": [
            model_with_tools.invoke(
                [
                    SystemMessage(
                        content="You are a helpful assistant tasked with performing arithmetic on a set of inputs."
                    )
                ]
                + state["messages"]
            )
        ],
        "llm_calls": state.get("llm_calls", 0) + 1,
    }


def tool_node(state: MessagesState):
    """Performs the tool call"""
    result = []
    last_message = state["messages"][-1]
    tool_calls = getattr(last_message, "tool_calls", [])
    for tool_call in tool_calls:
        tool = tools_by_name[tool_call["name"]]
        observation = tool.invoke(tool_call["args"])
        result.append(ToolMessage(content=observation, tool_call_id=tool_call["id"]))
    return {"messages": result}


def should_continue(state: MessagesState):
    """Decide if we should continue the loop or stop based upon whether the LLM made a tool call"""
    messages = state["messages"]
    last_message = messages[-1]
    tool_calls = getattr(last_message, "tool_calls", None)

    # 如果有工具调用，跑工具
    if tool_calls:
        return "tool_node"

    # 否则，停止（回复用户）
    return END


# Build workflow
agent_builder = StateGraph(MessagesState)

# Add nodes
agent_builder.add_node("llm_call", llm_call)
agent_builder.add_node("tool_node", tool_node)

# Add edges to connect nodes
agent_builder.add_edge(START, "llm_call")
agent_builder.add_conditional_edges("llm_call", should_continue, ["tool_node", END])
agent_builder.add_edge("tool_node", "llm_call")

# Compile the agent
agent = agent_builder.compile()

# Show the agent
from IPython.display import Image, display

png_bytes = agent.get_graph(xray=True).draw_mermaid_png()

# 保存到文件
with open("graph.png", "wb") as f:
    f.write(png_bytes)

print("图片已保存到 graph.png")

# Invoke
from langchain.messages import HumanMessage

messages: list[AnyMessage] = [HumanMessage(content="Add 3 and 4.")]
initial_state: MessagesState = {"messages": messages, "llm_calls": 0}
result = agent.invoke(initial_state)
for m in result["messages"]:
    m.pretty_print()

```

`MessagesState` 保存全图共享的数据。`messages` 存对话和工具消息，`llm_calls` 记录模型调用次数。示例还没加调用上限，后面需要补。`StateGraph(MessagesState)` 创建图。

`add_node` 注册节点，第一个参数是名称，第二个是实现。这里注册了 `llm_call` 和 `tool_node`。

`add_edge(START, "llm_call")` 先进入模型节点，`add_conditional_edges` 再用 should_continue 判断下一步：调用工具或结束。

should_continue 可以直接返回节点名。复用判断函数时，我更愿意让它返回业务路由名，再用第三个参数映射到当前节点：

```python
agent.add_node('a', node_a)
agent.add_node('b', node_b)

def common_continue(state: MessagesState):
    """通用判断逻辑"""
    messages = state["messages"]
    last_message = messages[-1]

    # 是否复杂任务
    if is_complex(last_message):
        return "complex"

    # 简单任务
    return 'simple'
  
agent.add_conditional_edges("llm_call", common_continue, {"complex": "node_a", "simple": "node_b"})
```

判断函数返回 complex 或 simple，图负责映射到对应节点。把边连回自身或前面的节点，就能形成循环。

也可以在节点内返回 `Command`：

```python
def router_node(state: State) -> Command[Literal["node_a", "node_b", "__end__"]]:
    """节点内部决定下一步，同时更新状态"""
    
    if state["score"] > 0.8:
        return Command(
            update={"status": "high"},      # ← 更新共享状态
            goto="node_a"                   # ← 动态路由到 node_a
        )
    elif state["score"] > 0.3:
        return Command(update={"status": "medium"}, goto="node_b")
    else:
        return Command(update={"status": "low"}, goto=END)
```

Command 可以同时更新状态和指定下一步。同一个节点别再重复添加条件边，避免走出多条路径。
