## SQLAlchemy 介绍

我用 SQLAlchemy 操作数据库，它支持直接写 SQL，也支持 ORM。这篇看 PostgreSQL 的用法。

## ORM

ORM（Object-Relational Mapping）把对象操作映射到数据库。先看例子：

```python
from sqlalchemy import create_engine, String
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

# 创建引擎（连接数据库）
engine = create_engine("postgresql+psycopg2://用户名:密码@主机:端口/数据库名", echo=True)

class Base(DeclarativeBase):
    pass  # 空类即可，元类在背后工作

class UUIDPrimaryKeyMixin:
    id: Mapped[uuid.UUID] = mapped_column(
        PG_UUID(as_uuid=True), primary_key=True, default=uuid.uuid4
    )

class User(Base, UUIDPrimaryKeyMixin):
    # 表名
    __tablename__ = "users"
    name: Mapped[str] = mapped_column(String(50))
    email: Mapped[str | None] = mapped_column(default=None)

# 创建表
Base.metadata.create_all(engine)

# 会话操作
with Session(engine) as session:
    # 新增：对象 → 自动转成 INSERT SQL
    user = User(name="李四", email="li@example.com")
    session.add(user)      # 加入会话（追踪状态）
    session.commit()       # 自动执行 INSERT
    
    # 查询：自动转成 SELECT SQL
    result = session.execute(
        select(User).where(User.name == "李四")
    )
    u = result.scalar_one()
    
    # 修改：Session 自动追踪变化 → 自动执行 UPDATE
    u.email = "new@example.com"
    session.commit()       # 自动执行 UPDATE
    
    # 删除
    session.delete(u)
    session.commit()       # 自动执行 DELETE
```

定义映射后，用对象执行增删改查：

```python
from sqlalchemy import select, insert, update, delete, func
from sqlalchemy.orm import Session, joinedload, selectinload

with Session(engine) as session:
    
    # ---------- 查 ----------
    # 按主键
    user = session.get(User, 1)
    
    # 单个（确定有）
    user = session.execute(select(User).where(User.id == 1)).scalar_one()
    
    # 单个（可能有）
    user = session.execute(select(User).where(User.email == "a@b.com")).scalar_one_or_none()
    
    # 列表
    users = session.execute(select(User).where(User.age > 18)).scalars().all()
    
    # 第一个
    user = session.execute(select(User)).scalars().first()
    
    # 计数
    count = session.execute(select(func.count()).select_from(User)).scalar()
    
    # 关联预加载（防 N+1）
    users = session.execute(
        select(User).options(selectinload(User.posts))
    ).scalars().all()
    
    # ---------- 增 ----------
    session.add(User(name="张三"))
    session.add_all([user1, user2])
    session.commit()
    
    # 批量插入（Core 方式）
    session.execute(insert(User), [{"name": "A"}, {"name": "B"}])
    session.commit()
    
    # ---------- 改 ----------
    user.name = "新名字"        # 改对象属性
    session.commit()            # 自动 UPDATE
    
    # 批量改
    session.execute(update(User).where(User.id == 1).values(name="新名字"))
    session.commit()
    
    # ---------- 删 ----------
    session.delete(user)
    session.commit()
    
    # 批量删
    session.execute(delete(User).where(User.id == 1))
    session.commit()
```

`Mapped` 标注 Python 属性类型，`mapped_column` 配置数据库列。`Mapped[uuid.UUID]` 把 id 标成 UUID，`mapped_column(PG_UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)` 指定列类型、主键和默认值。

**`mapped_column` 常用参数**

| 参数                 | 说明                                          | 示例                                          |
| :------------------- | :-------------------------------------------- | :-------------------------------------------- |
| **`primary_key`**    | 是否主键                                      | `mapped_column(primary_key=True)`             |
| **`nullable`**       | 是否允许 NULL（默认根据 `Mapped[类型]` 推断） | `mapped_column(nullable=False)`               |
| **`default`**        | Python 默认值（插入时生成）                   | `mapped_column(default=0)`                    |
| **`server_default`** | 数据库默认值（由数据库生成）                  | `mapped_column(server_default=text("now()"))` |
| **`index`**          | 是否创建索引                                  | `mapped_column(index=True)`                   |
| **`unique`**         | 是否唯一约束                                  | `mapped_column(unique=True)`                  |
| **`autoincrement`**  | 是否自增（主键整型默认 True）                 | `mapped_column(autoincrement=True)`           |
| **`comment`**        | 字段注释                                      | `mapped_column(comment="用户姓名")`           |
| **`type_`**          | 显式指定列类型（通常自动推导）                | `mapped_column(type_=String(100))`            |
| **`ForeignKey`**     | 外键关联                                      | `mapped_column(ForeignKey("users.id"))`       |
| **`onupdate`**       | 更新时自动赋值                                | `mapped_column(onupdate=func.now())`          |

## 事务封装

事务把一组操作放在一起提交，失败时回滚。商品入库要更新调拨单、库存和产品信息，库存校验失败时，前面的修改也得撤回。

我把提交和回滚收进一个封装：

```python
@asynccontextmanager
async def session_scope(
    factory: async_sessionmaker[AsyncSession],
) -> AsyncIterator[AsyncSession]:
    """唯一事务边界：成功提交，失败回滚。HTTP / Celery / eval 均经此进入。"""
    async with factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise
            
# 使用时候
async with session_scope(session_factory) as session:
  # 进行操作
  user = User(name="李四", email="li@example.com")
  session.add(user)
  # 事务不提交，更新数据库预览单次结果
  session.flush()
```

`flush` 把修改写到数据库，不提交事务；`commit` 提交事务。后续失败时，用 `session.rollback()` 回滚。

`asynccontextmanager` 封装 session 的创建和关闭。外部用 `async with`，退出时释放资源。
